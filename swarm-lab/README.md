# Container Orchestration with Docker Swarm & Docker Stack

## Objectives
- Initialize and manage a single-node Docker Swarm orchestration cluster.
- Deploy declarative multi-container applications using Docker Stack and overlay networks.
- Perform dynamic scaling, rolling updates with zero downtime, and node placement constraint configuration.
- Implement container health checks, resource limits (CPU/Memory reserves), and cluster monitoring workflows.

## Technology Stack
- Docker Engine & Docker Swarm Mode
- Nginx Alpine & Redis Alpine
- Docker Compose File Format (v3.8) & Overlay Networking

## Key Skills Demonstrated
- **Distributed Orchestration:** Transitioning isolated Docker engines into managed clusters with built-in load balancing.
- **High Availability & Scaling:** Dynamically scaling service replicas across cluster nodes using declarative YAML specifications.
- **Zero-Downtime Deployments:** Executing rolling updates and automated restart policies to ensure production resilience.
